# Claims Verification Register

*Maintenance file (not an article). The **system of record** for single-source, contested, contradictory, or date-stamped claims. Maintained each run; replaces an ephemeral per-digest list.*

*Last updated: <YYYY-MM-DD>*

Status legend: `OPEN` (needs a 2nd source) · `CORROBORATED` (≥2 independent sources — upgrade the article tag) · `CONTESTED` (sources disagree — annotate both locations) · `RESOLVED` (settled, e.g. a reconciled apparent-contradiction) · `RETIRED` (shown false/misattributed — supersede in the article).

Process each run: add OPEN rows for new single-source/contested claims; run a verification pass (ideally an independent subagent); update status with verdict + sources + date; after ~90 days with no corroboration, downgrade the article wording; surface still-open items into the digest.
